# media/

Put your test clips here (any sub-folder layout works; the suite classifies each file by its content).

**Everything in this folder except this README is git-ignored.** Never commit media.

How to fill it: [docs/media-clips.md](../docs/media-clips.md) ([Türkçe](../docs/media-clips.tr.md)).

Quick start without any media of your own:

```powershell
.\tools\get-test-videos.ps1 -Set starter     # Windows
```
```bash
bash tools/get-test-videos.sh --set starter  # Linux
```
